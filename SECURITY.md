# Security Policy

## Supported Versions

GPU Flight Recorder is currently a public beta. Security fixes are handled for the latest beta release only.

| Version | Supported |
| --- | --- |
| 0.1.x beta | Yes |
| older snapshots | No |

## Reporting a Vulnerability

Use GitHub private vulnerability reporting if it is enabled for the repository.

If private reporting is not available, open a minimal public issue that describes the affected area without attaching private logs, dump files, support bundles, or machine-specific data. The maintainer can ask for a safer follow-up path if more detail is needed.

## Diagnostic Data Warning

This project works with local machine diagnostics. Do not post full support bundles, Windows event messages, dump filenames, process lists, or monitor/device details publicly unless you have reviewed them first.

## No SLA

This is a personal/portfolio beta project. There is no guaranteed response time, patch timeline, or commercial support commitment.
